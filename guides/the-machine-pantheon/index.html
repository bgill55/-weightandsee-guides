🎯 Key Takeaways

  • 1The Machine Pantheon uses seven specialized AI archetypes (Themas, Medis, Hefistus, Nemosini, Apollo, Asclepius, Dataless) to enforce strict role boundaries and prevent hallucinations.
  • 2Workflow starts when a developer issues the `/autopilot` command, which Detalist intercepts to begin a multi‑tiered schema creation.
  • 3Phase 1 locks down formal contracts, TypeScript schemas, and test assertions before any code is generated.
  • 4Phase 2 decomposes requirements into actionable tasks, splits coding and documentation research, and runs a continuous review‑debug‑synthesize loop.
  • 5Naming the AI agents with mythological titles clarifies responsibilities, reduces cognitive load, and makes the automation pipeline transparent.

  • Access to a Gemini Notebook environment with Node.js and Git installed.

📝 Step-by-Step Guide

1

Step 1: Install the Detalist Orchestrator

Clone the Pantheon repository and install the orchestrator package. This sets up the `/autopilot` command and all seven archetype modules.

git clone https://github.com/machine-pantheon/pantheon.git && cd pantheon && npm install && npm link detalist
2

Step 2: Initialize a New Project

Create a project directory and generate the initial schema contract that will govern all subsequent steps.

detalist init my‑awesome‑app && cd my‑awesome‑app && detalist schema --output contracts/schema.json
3

Step 3: Generate Formal Contracts and Test Assertions

Themas creates TypeScript interfaces and Jest test assertions based on the schema, ensuring the system has a locked‑down contract before coding begins.

detalist autopilot --stage contracts --output contracts/assertions.ts
4

Step 4: Decompose Tasks and Launch Parallel Research

Medis reads the contracts and produces a numbered task list. Hefistus starts coding, while Nemosini simultaneously fetches real‑world documentation to ground the implementation.

detalist autopilot --stage tasks --output tasks.json && detalist code --task 1 --file src/service.ts & detalist research --source https://api.example.com/docs
5

Step 5: Review, Debug, and Synthesize

Apollo reviews each generated file, Asclepius isolates and fixes errors, and Dataless compiles a final report. This loop repeats until all files pass review.

detalist review --file src/service.ts && detalist debug --error "TypeError: undefined" && detalist synthesize --output report.md

💡 Pro Tips

Pro Tip: Always lock the schema before issuing `/autopilot`; otherwise the system will reject later steps.
Pro Tip: Use the `--strict` flag with `detalist schema` to enforce exhaustive test coverage.
Pro Tip: Monitor Apollo’s review logs in real time to catch structural issues early.
Pro Tip: When fetching external docs, specify a version pin to avoid breaking changes mid‑project.

⚠️ Common Pitfalls

Watch Out: Skipping the contract phase leads to hallucinated function signatures and runtime errors.
Watch Out: Neglecting to pin dependency versions in the research step can cause compatibility failures during synthesis.
Watch Out: Ignoring Apollo’s pass/fail verdicts results in code that fails the final security review.

❓ Frequently Asked Questions

What exactly does the `/autopilot` command do?

It tells Detalist to start a new workflow, which begins by generating contracts, decomposing tasks, and spawning the seven specialized agents.

Do I need to write any code manually?

No. All code is produced by Hefistus based on tasks defined by Medis; however, you can intervene and edit files if needed.

How does The Machine Pantheon prevent AI hallucinations?

By enforcing strict contracts and type‑safe schemas before any code is written, and by requiring Apollo’s review of every generated file.

Can I customize the seven archetype roles?

The current implementation uses fixed archetypes, but the framework is extensible; you can add custom agents as long as they adhere to the contract interface.

Where are the generated test files stored?

Test assertions are placed in `contracts/assertions.ts` and executed via the standard Jest test runner integrated with Detalist.
