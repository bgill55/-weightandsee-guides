Step 1: Setting up Agent Reach

To get started with Agent Reach, you need to send a POST request to the API endpoint with a JSON payload containing the target URL and an optional CSS selector.

curl -X POST 'https://api.agentreach.com/fetch' -H 'Content-Type: application/json' -d '{"url": "https://example.com", "css_selector": ".article"}'
2

Step 2: Integrating Agent Reach with LangChain

To integrate Agent Reach with LangChain, you need to replace the default `Browser` chain with `AgentReachBrowser` and import the required module.

from agentreach import AgentReachBrowser; browser = AgentReachBrowser()

❓ Frequently Asked Questions

How does Agent Reach provide free internet access?

Agent Reach provides free internet access by eliminating token-metering and per-query bills, allowing you to query thousands of pages without incurring additional costs.

Can I use Agent Reach with LangChain?

Yes, Agent Reach is compatible with LangChain and can be integrated by replacing the default `Browser` chain with `AgentReachBrowser`.

What is the latency of Agent Reach?

The latency of Agent Reach is in the sub-second range for most static pages, comparable to OpenAI's browsing endpoint but without the per-token expense.
