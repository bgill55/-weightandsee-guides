Step 1: Clone and Install Daedalus

To get started, clone the Daedalus repository from GitHub to your local machine. This standalone assistant runs entirely in your terminal, so ensure you have Python dependencies ready if the project requires a build step.

git clone https://github.com/bgill55/daedalus
2

Step 2: Connect Local LLM Backend

Configure Daedalus to connect to your preferred local inference engine. You can route requests to LM Studio, Ollama, or a local vLLM instance. This ensures the agent operates without making external cloud API calls.

daedalus --connect ollama
# or daedalus --connect lm-studio
3

Step 3: Initiate SpecFirst Workflow

Start a new project task using the slash spec command. This triggers the SpecFirst architecture, where the agent clarifies requirements and generates both a machine-readable JSON contract and a human-readable Markdown specification.

/spec
