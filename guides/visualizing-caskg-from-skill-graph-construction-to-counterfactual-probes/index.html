Counterfactual-Causal Skill Graphs

CaSKG employs these graphs to capture the cause-and-effect relationships between tasks and skills, allowing for more accurate retrieval of relevant skills in new situations.

Skill Graph Construction

The skill graph is built using historical data on how different skills are used together and what outcomes result from their combinations.

Counterfactual Probes

CaSKG uses counterfactual probes to test and refine its skill graph by manipulating variables and analyzing the results.

Scalability

CaSKG is designed to be highly scalable, making it suitable for applications that require handling large volumes of tasks across multiple LLM backbones.

⚙️ Technical Background

CaSKG stands for Counterfactual-Causal Skill Graph and is a framework that uses these graphs to efficiently manage agent skills across six different Large Language Model (LLM) backbones. By analyzing historical data on skill usage, CaSKG constructs counterfactual-causal skill graphs that capture cause-and-effect relationships between tasks and skills.
