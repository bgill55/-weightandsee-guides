❓ Frequently Asked Questions

How do I handle multiple users in a group chat?

Each incoming message has a unique chat_id. The bot stores recent messages per chat_id, ensuring context isolation.

What happens if the container restarts?

Conversation history is persisted by mounting a host directory as a volume and serializing messages to JSON files.

Can I use GPU acceleration?

Yes, add the `runtime: nvidia` flag to the Docker Compose file and install the NVIDIA Container Toolkit for GPU support.

How do I choose the right model size?

Smaller models like grok-3b-tiny are suitable for resource-constrained devices, while larger models offer better performance.

Is there a way to integrate with other apps?

Grok Bot uses connectors to interact with apps via signed-in credentials, browser automation, or APIs. It can also communicate with other bots via a message bus.
