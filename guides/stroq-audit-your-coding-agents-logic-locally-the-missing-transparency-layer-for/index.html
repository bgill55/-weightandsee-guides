Stroq: Audit Your Coding Agent's Logic Locally – The Missing Transparency Layer for AI Developers

Stroq is an open‑source transparency layer that lets developers audit the logic of any AI coding assistant locally. By intercepting API calls, logging prompts, responses, and internal state to a JSON audit trail, Stroq turns opaque AI code generation into a verifiable, replayable workflow. This guide walks you through installing Stroq, configuring your LLM provider, capturing audit logs, replaying decisions, and generating human‑readable reports—all with concrete CLI commands and configuration snippets.

🎯 Key Takeaways

  • 1Stroq adds only 5‑10 ms of latency per request, making it virtually transparent for typical AI coding pipelines.
  • 2It works with any REST‑based LLM provider (OpenAI, Anthropic, etc.) by acting as a proxy that logs every interaction.
  • 3A single command `stroq run --agent openai-codex --log ./audit.log` starts real‑time JSON logging of prompts, token streams, and internal flags.
  • 4You can replay logged sessions with `stroq replay --log ./audit.log --output ./replay.json` to debug specific decisions without re‑running the whole pipeline.
  • 5Stroq can export a concise, human‑readable report (table of actions, decisions, confidence scores) for pull‑requests or security audits.
  • 6The audit trail includes timestamps, raw prompt, raw response, and the agent’s internal state dictionary for full traceability.
  • 7All configuration is done via environment variables and CLI flags—no complex SDK integration required.

📋 Prerequisites

  • Stroq CLI installed (`pip install stroq` or `cargo install stroq`).
  • Valid API credentials for your chosen LLM provider (e.g., `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`).

📝 Step-by-Step Guide

1

Step 1: Install the Stroq CLI

Download and install the Stroq command‑line tool. Using pip is the quickest on most Linux/macOS environments; using cargo is recommended if you prefer Rust‑based tooling. The installation creates the `stroq` executable in your PATH.

pip install stroq
# or
cargo install stroq
2

Step 2: Export your LLM provider API key

Set the appropriate environment variable for the provider you intend to use. Stroq reads these variables automatically; never hard‑code keys in scripts. For OpenAI use `OPENAI_API_KEY`, for Anthropic use `ANTHROPIC_API_KEY`.

export OPENAI_API_KEY=sk-your-openai-key
# or
export ANTHROPIC_API_KEY=ant-your-anthropic-key
3

Step 3: Start an audit session

Run Stroq with the `--agent` flag to specify the coding assistant (e.g., `openai-codex`) and the `--log` flag to define where the JSON audit trail will be written. The command runs the agent normally while Stroq intercepts each request/response.

stroq run --agent openai-certs --log ./audit.log
4

Step 4: Replay and inspect logged decisions

Use the replay subcommand to convert the raw audit log into a structured JSON file (`replay.json`). This output contains a step‑by‑step view of prompts, responses, timestamps, and internal flags, enabling targeted debugging.

stroq replay --log ./audit.log --output ./replay.json

💡 Pro Tips

Pro Tip: Use absolute paths for `--log` and `--output` to avoid confusion when you move or copy the project directory.
Pro Tip: Add `--verbose` to the `stroq run` command to see real‑time logging of intercepted requests on stdout.
Pro Tip: Store API keys in a secrets manager or `.env` file and load them with `dotenv` rather than printing them to shell history.
Pro Tip: If you need to replay only a specific time window, filter the audit log with `jq 'select(.timestamp >= "2024-09-01T12:00:00Z" and .timestamp <= "2024-09-01T12:30:00Z")'` before feeding it to `stroq replay`.

⚠️ Common Pitfalls

Watch Out: Pitfall 1: Forgetting to set the API key results in authentication errors and empty audit logs. Always verify `echo $OPENAI_API_KEY` or `echo $ANTHROPIC_API_KEY` before running Stroq.
Watch Out: Pitfall 2: Writing the audit log to a directory you don’t have write permissions for (e.g., `/var/log/stroq`). Use a writable location like `./audit.log` or `/tmp/stroq/audit.log` for testing.

❓ Frequently Asked Questions

How does Stroq affect the latency of my AI coding assistant?

Stroq adds roughly 5‑10 ms of overhead per request on a typical RTX 4090. This is negligible compared to the usual 200 ms round‑trip time of LLM APIs.

Can I use Stroq with providers other than OpenAI and Anthropic?

Yes. Stroq acts as a generic proxy for any REST‑based LLM provider that exposes a standard chat/completion endpoint. Simply set the appropriate API key and use the provider‑specific agent name.

What information is stored in the audit log?

Each entry contains a timestamp, the raw prompt sent to the agent, the raw response received, and the agent’s internal state dictionary (including flags, confidence scores, and token usage).

How do I debug a specific mistake shown in the audit log?

Use `stroq replay` to generate a step‑by‑step JSON view, locate the problematic request/response pair, and adjust your prompt template or agent configuration. Replay only the relevant segment to verify the fix without rerunning the entire pipeline.
