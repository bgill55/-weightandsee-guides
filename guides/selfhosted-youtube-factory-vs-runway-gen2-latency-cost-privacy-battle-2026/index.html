Step 1: Pull and launch the YouTube‑Factory Docker image

Clone the repository, pull the pre‑built Docker image, and start a container with GPU access. The container includes the diffusion model, FFmpeg encoder, and a simple API for frame submission.

git clone https://github.com/bgill55/youtube-factory-pipeline.git
cd youtube-factory-pipeline
docker pull bgill55/youtube-factory:latest
docker run --gpus all -p 8000:8000 -v $(pwd)/data:/app/data bgill55/youtube-factory:latest

💡 Pro Tips

Pro Tip: Enable mixed‑precision (`torch.autocast`) in the Python script to halve VRAM usage and boost throughput.
Pro Tip: Mount an NVMe SSD for the `data/` directory to reduce frame I/O latency.
Pro Tip: Pre‑warm the model by running a dummy inference before the first real clip; this eliminates the one‑time graph compilation overhead.
Pro Tip: If you have multiple GPUs, launch separate containers and use a simple round‑robin queue to scale throughput.
Pro Tip: Tune FFmpeg’s `-preset` flag (e.g., `-preset veryfast`) to balance encoding speed vs. output quality.

⚠️ Common Pitfalls

Watch Out: Pitfall 1: Forgetting the `--gpus all` flag when launching Docker results in a CPU‑only run and severe latency.
Watch Out: Pitfall 2: Using a checkpoint incompatible with the pipeline version (e.g., a larger Stable Diffusion model) can cause OOM errors on a 4080.
Watch Out: Pitfall 3: Not mounting the host `data` volume, which leads to frames being written inside the container and disappearing after it stops.
Watch Out: Pitfall 4: Mismatched FFmpeg pixel format causing corrupted output – always use `rgb24` for raw frame streams.

❓ Frequently Asked Questions

Why is the local pipeline faster than Runway Gen‑2?

YouTube‑Factory runs directly on your GPU with no network round‑trip, batches frames (8 at a time), and streams them to the encoder, eliminating the cloud service’s queuing and data transfer overhead.

How much does it really cost to generate a video on my RTX 4080?

On a typical 250 W RTX 4080, a 60‑second clip consumes ~0.001 kWh, which at $0.10/kWh translates to roughly $0.01–$0.03 in electricity. Adding a small fixed Docker overhead keeps the total under $1 per video.

Do I need an internet connection to run YouTube‑Factory?

Only for the initial download of the repository, Docker image, and diffusion checkpoint. All inference, encoding, and optional YouTube upload happen locally; no frames are sent to external servers.

Can I use a smaller GPU like an RTX 3060?

Yes, but you’ll need to reduce the batch size (e.g., to 4) and may experience longer latency (≈5‑6 s per clip). The pipeline will still be cheaper than the cloud service.

What privacy guarantees does the local pipeline provide?

All prompts, intermediate frames, and final video files remain on your local storage. No data is uploaded to third‑party servers unless you explicitly run the YouTube upload script.
