📝 Step-by-Step Guide

1

Step 1: Hardware and Driver Configuration

Install your GPU into the PCIe slot and connect power. Ensure you have the latest NVIDIA drivers installed and specifically install CUDA 12.2. Verify the system recognizes the GPU correctly before proceeding.

nvidia-smi
2

Step 2: Clone Opencode and Download Weights

Clone the Opencode repository from GitHub to your local machine. Run the provided script within the repository to automatically download the 12GB OpenClaude 3.5 model weights. Using a fast SSD is recommended here to speed up the download and extraction process.

git clone https://github.com/anomalyco/opencode
3

Step 3: Configure LM Studio

Launch LM Studio and navigate to the model settings. Point the application to the folder where you downloaded the Claude 3.5 weights. Enable GPU acceleration offload and set the context window to 8k tokens to balance memory usage and performance.

4

Step 4: Launch Server and Verify

Click 'Start Server' in the LM Studio interface. Wait for the green ready indicator to appear. Run a complex prompt (e.g., regarding quantum tunneling) to verify token throughput and latency. On an RTX 4060, look for speeds around 22 tokens/sec with latency under 50ms.

💡 Pro Tips

Pro Tip: Use a dedicated SSD for storing model weights to drastically cut down model loading times.
Pro Tip: Monitor your VRAM usage in `nvidia-smi` while adjusting the context window to find the sweet spot between context length and stability.
Pro Tip: If you encounter out-of-memory errors, try reducing the context window size or partially offloading layers to the CPU.

⚠️ Common Pitfalls

Watch Out: Outdated Drivers: Failing to install CUDA 12.2 or the latest NVIDIA drivers will result in the GPU not being detected by LM Studio.
Watch Out: Slow Storage: Running the model directly from a hard drive (HDD) instead of an SSD will cause significant bottlenecks during loading and inference.

❓ Frequently Asked Questions

What internet connection is required for this setup?

An internet connection is only required for the initial step of cloning the repository and downloading the 12GB model weights. Once the files are local, the entire LLM runs offline.

Can I run this setup on a GPU with less VRAM than an RTX 4060?

While possible, you may need to quantize the model or offload more layers to your system RAM, which will significantly reduce inference speed (tokens per second).

How much disk space is required?

You need at least 12GB for the model weights, plus additional space for the OS, LM Studio, and the Opencode repository. A total of 30GB+ free space is recommended.

Is the performance comparable to the cloud version of Claude?

While the model intelligence is similar, the inference speed (22 tokens/sec) is slower than enterprise cloud APIs. However, it offers low latency (<50ms) suitable for real-time chat and complete data privacy.
