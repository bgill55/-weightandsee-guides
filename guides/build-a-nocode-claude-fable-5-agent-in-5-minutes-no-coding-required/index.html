⚠️ Common Pitfalls

Watch Out: Pitfall 2: Inconsistent Prompting - Using slightly different prompts for each model will invalidate the comparison; ensure prompt sets are identical.
Watch Out: Pitfall 3: Hardware Bottlenecks - Running tests on underpowered hardware will artificially inflate latency for both models, hiding Fable 5's performance advantage.
