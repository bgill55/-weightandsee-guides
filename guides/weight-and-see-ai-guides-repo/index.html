📝 Step-by-Step Guide

1

Clone Repository & Environment Setup

Clone the official repository and set up your virtual environment.

git clone https://github.com/aaif-goose/goose
cd goose
pip install -r requirements.txt
2

Model Backend Configuration

Configure the target model provider (Ollama, vLLM, or cloud API keys) in your config file.

export MODEL_PROVIDER=ollama
export MODEL_NAME=llama4
goose configure
3

Execution & Workflow Automation

Launch the CLI agent to begin automated refactoring and code generation.

goose run --prompt 'Refactor main pipeline and update tests'
