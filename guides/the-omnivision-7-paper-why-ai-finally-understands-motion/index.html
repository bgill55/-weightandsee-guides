Step 2: Load the Spacetime‑Attention Model

Instantiate the model in PyTorch. The `OmniVision7` class expects a 5‑D tensor of shape `(B, C, T, H, W)` where `T` is the number of frames. Provide a video clip as a stack of frames.

```python
import torch
from omni_vision_7 import OmniVision7

# Load the pre‑trained weights
model = OmniVision7.from_pretrained('models/omni-vision-7.ckpt')
model.eval()

# Prepare a video tensor (e.g., 16 frames of 256x256 RGB)
video = torch.randn(1, 3, 16, 256, 256)  # Replace with real frames

# Forward pass – the model processes the entire volume at once
with torch.no_grad():
    output = model(video)  # output shape: (1, 3, 16, 256, 256)
```

Step 3: Anchor Geometry to Preserve Object Identity

During training the model learns to keep pixels in consistent spatial locations. When generating a video, you can enforce this by feeding a conditioning mask that marks static objects (e.g., a hand). The mask is broadcast across the temporal dimension.

```python
# Create a binary mask for the hand region (1 = hand, 0 = background)
mask = torch.zeros(1, 1, 16, 256, 256)
mask[:, :, :, 100:200, 120:220] = 1  # example coordinates

# Pass mask to the model’s forward method
with torch.no_grad():
    output = model(video, mask=mask)
```

Step 4: Validate Temporal Coherence and Physics

Run automated checks on the generated video. Compute per‑frame optical flow consistency, verify lighting gradients, and detect flicker using a simple variance filter across frames.

```python
import cv2
import numpy as np

# Convert output tensor to NumPy array
frames = output.squeeze().permute(1, 2, 3, 0).cpu().numpy()  # shape (T, H, W, C)

# Compute per‑frame variance to detect flicker
var_per_frame = [np.var(frame) for frame in frames]
print('Average variance:', np.mean(var_per_frame))

# Simple optical flow consistency check between consecutive frames
for i in range(len(frames)-1):
    flow = cv2.calcOpticalFlowFarneback(frames[i], frames[i+1], None,
                                        pyr_scale=0.5, levels=3, winsize=15,
                                        iterations=3, poly_n=5, poly_sigma=1.2, flags=0)
    mag, ang = cv2.cartToPolar(flow[...,0], flow[...,1])
    if np.mean(mag) > 5:  # arbitrary threshold
        print('High motion inconsistency at frame', i)
```

❓ Frequently Asked Questions

How many GPU memory does OmniVision‑7 need for a 16‑frame 256×256 video?

Approximately 16–20 GB of VRAM with FP16 precision; 32 GB is recommended for larger resolutions or batch sizes.

Can I use the model for real‑time inference?

Real‑time inference is challenging due to the 3‑D volume requirement, but with model pruning and a 4‑frame sliding window you can approximate near real‑time performance on a high‑end GPU.

What is the difference between Spacetime‑Attention and conventional 2‑D attention?

Conventional attention processes each frame independently; Spacetime‑Attention extends the key‑value pairs across the temporal axis, allowing the model to attend to past and future frames simultaneously.

How do I integrate a custom dataset into the training pipeline?

Follow the repo’s `train.py` script; replace the data loader to yield tensors of shape `(B, C, T, H, W)` and add your own `TemporalDataset` class.

Is there a public API for the OmniVision‑7 model?

No official API yet; the model is distributed as a PyTorch package. You can wrap it in a Flask or FastAPI server if needed.
