Daedalus v3.30.11

This tutorial walks developers through Daedalus v3.30.11, a local‑first multi‑agent AI coding framework. It demonstrates how to install the tool, generate strict specifications, run specialized subagents, and use self‑healing loops to build private AI‑driven software without cloud dependencies.

🎯 Key Takeaways

  • 1SpecFirst architecture prevents contract drift and gold drift by generating synchronized human‑readable and machine‑readable specs before any code is written.
  • 2Daedalus decomposes tasks into five specialized subagents (planner, coder, researcher, debugger, reviewer) orchestrated by an embedded router.
  • 3A tiered routing system (fast, standard, intelligence) ensures heavy computation only runs when needed, keeping execution within 8 GB VRAM limits.
  • 4Hard‑capped context length of 8192 tokens prevents VRAM overflow and eliminates CPU fallback slowdown.
  • 5Circuit breakers detect and abort infinite command loops after three identical attempts, forcing alternative strategies.
  • 6Automated spec verification and a self‑healing loop continuously validate generated code against the spec, rolling back on failures.
  • 7The framework can autonomously open pull requests, run verification, and notify reviewers, enabling a fully hands‑off development pipeline.

📋 Prerequisites

  • Git and Node.js (for cloning and installing Daedalus)
  • An LLM runtime with at least 8 GB VRAM (e.g., LM Studio or similar local model server)
  • Access to a Discord community for support (https://discord.gg/GPH2ZH57up)
  • Basic familiarity with TypeScript and terminal‑based workflows

📝 Step-by-Step Guide

1

Step 1: Clone and install Daedalus

Clone the repository, install dependencies, and start the Daedalus daemon. This prepares the local MCP filesystem and loads the project rules.

```bash
git clone https://github.com/bgill55/daedalus.git
dcd daedalus
npm install
# Start the daemon (uses the embedded model router)
daedalus daemon --context-limit 8192
```
2

Step 2: Generate a specification

Create both a human‑readable markdown spec and a strict JSON contract for the desired feature. The CLI automatically injects these contracts into every subagent’s context.

```bash
# Generate spec for a helper function to validate version strings
daedalus spec "/spec \"Add a helper function to validate version string format and export it in version.ts\""
