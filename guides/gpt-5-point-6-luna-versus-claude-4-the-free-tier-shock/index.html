⚙️ Technical Background

GPT‑5.6 Luna builds on a dense “Sol” model that leverages a Mixture‑of‑Experts (MoE) architecture, where most expert pathways are pruned (≈90 % sparsity) to lower inference cost. Speculative decoding runs a small draft model ahead of the main model, pre‑generating tokens that are later verified, which boosts throughput to >100 tokens/sec. The massive 128k token context window is facilitated by transformer optimizations that keep activation memory within data‑center limits, allowing the model to handle very large inputs without external chunking.
