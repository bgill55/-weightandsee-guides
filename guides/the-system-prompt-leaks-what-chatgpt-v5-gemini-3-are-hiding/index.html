The ChatGPT v5 leak reveals a strict persona block ('helpful, respectful assistant that never discloses internal policies') followed by a safety clause that triggers automatic refusals for illegal activity, self-harm, or political persuasion. This confirms that model refusals are the result of explicit, hard-coded rules rather than emergent behavior.

Gemini 3.5's hidden prompt includes specific instructions to provide neutral summaries for disputed topics and avoid taking sides. It specifically mandates citing official sources without speculation regarding election outcomes and features a 'prompt injection guard' designed to strip user-supplied system messages to prevent overrides.

Extraction via Inference API Vulnerability

Researchers obtained these prompts by exploiting a temporary file-write vulnerability within the inference API. The prompts were stored in a non-exposed 3KB configuration file (base-64 encoded) residing on the same disk as the model weights, demonstrating that compromising the inference node exposes the entire instruction set.

Emergence of 'Inverse Prompting' Attacks

Public knowledge of system prompts allows for 'inverse prompts' designed to align with hidden rules. By framing requests as 'research summaries' rather than direct instructions, attackers can bypass refusal clauses. Documented tests show this technique achieves a 27% success rate in circumventing safety filters.

⚙️ Technical Background

System prompts (or system messages) are high-level instructions fed into Large Language Models (LLMs) prior to user interaction to define behavior, persona, and safety boundaries. Unlike the model weights (the neural network parameters), these prompts act as the runtime configuration layer. They are critical for alignment, ensuring the model adheres to safety guidelines and brand voice, but they represent a security surface if not adequately isolated from the inference environment.

❓ Frequently Asked Questions

How exactly were the system prompts leaked?

Researchers exploited a temporary file-write vulnerability in the inference API. This allowed them to access a configuration file on the server's disk, decode the base-64 payload, and read the plain-text system instructions.

What is the difference between ChatGPT v5 and Gemini 3.5's leaked prompts?

ChatGPT v5's prompt focuses heavily on a strict persona and hard refusal of illegal or harmful requests. Gemini 3.5's prompt focuses more on controversy handling, requiring neutrality in disputes and strict citation of sources for political topics.

Can I still use these models safely despite the leak?

Yes, for general use. However, developers should implement middleware to sanitize user inputs and be aware that specific prompt structures might be used to bypass standard safety filters.

What does 'inverse prompting' mean?

Inverse prompting is a technique where a user crafts a request to appear compliant with the model's hidden system instructions (e.g., framing a harmful request as a 'neutral research summary') to trick the model into bypassing its refusal logic.
