📝 Step-by-Step Guide

1

Step 1: Install the Last30Days Skill

Use the Agent Skills CLI to download and install the Last30Days skill globally. This command fetches the necessary package from the registry and sets it up for use within your agent environment.

npx skills add mvanhorn/last30days-skill -g
2

Step 2: Configure API Credentials

Load the Last30Days skill into your agent host configuration. Access the configuration variables for the skill and paste your API keys for Reddit, X, and Polymarket. Ensure you have enabled the specific API scopes required for read access to posts, comments, and market data.

configuration_variables:
  REDDIT_API_KEY: "your_reddit_key"
  X_API_BEARER_TOKEN: "your_x_token"
  POLYMARKET_API_KEY: "your_polymarket_key"
3

Step 3: Execute a Discovery Query

Run the Last30Days script in discovery mode using Python. This triggers the parallel process: scraping the top 50 posts from relevant subreddits, pulling activity from X hashtags, and querying Polymarket for active event contracts related to your topic.

python3 skills/last30days/scripts/last30days.py --discover "AI agents" --emit=json
4

Step 4: Analyze the Output Brief

Review the generated markdown brief. Pay attention to the 'Market Confidence' metric associated with each citation. A high confidence score indicates that social sentiment is backed by capital movement (smart money), whereas a high social score with low market confidence suggests hype or manipulation.

Output format: Markdown brief with citations including {"source": "Reddit", "confidence": 0.85, "market_odds": "Yes 65%"}

💡 Pro Tips

Pro Tip: Look for low social scores paired with high market scores to identify 'information arbitrage' opportunities where the crowd hasn't caught up to smart money.
Pro Tip: Use the --emit=json flag if you want to pipe the output into another tool or database for further analysis.
Pro Tip: Run the agent locally rather than in a cloud environment to ensure your API keys never leave your machine.

⚠️ Common Pitfalls

Watch Out: Incorrect API Scopes: Failing to enable specific read scopes for Reddit or X will result in authentication failures during the scraping phase.
Watch Out: Ignoring Market Validation: Assuming that a high number of Reddit upvotes equates to truth, without checking if the Polymarket odds are stagnant or dropping.
Watch Out: Rate Limits: While the skill handles rate limiting internally, using free-tier API keys may result in throttling during high-frequency discovery runs.

❓ Frequently Asked Questions

Do I need to know how to code to use this skill?

No, the skill is designed for zero-code usage. You install it via CLI, paste API keys into a configuration file, and run it with a single command.

What data sources does the skill use?

It primarily uses Reddit (upvotes/comments), X (likes/activity), and Polymarket (prediction market odds) to score research validity.

How does the scoring engine work?

It weights social sentiment against liquidity and price movement in prediction markets. A 'Market Confidence' metric is generated to show if buzz is backed by financial risk.

Can I run this locally?

Yes, the guide and script support local hosting, ensuring your API keys for Reddit, X, and Polymarket do not leave your machine.
