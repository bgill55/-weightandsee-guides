📝 Step-by-Step Guide

1

Step 1: Make AGENTS.md your canonical context file

Write all agent-facing project instructions into AGENTS.md at the repository root. Cursor and Devin will pick it up natively with no further setup. Organize it into explicit sections — build/install commands, test suite invocation, linting rules, coding conventions, and security policies — because agents rely on this file for behavior like which tests are mandatory and which credentials must never be logged. This file becomes the single source of truth every later step derives from.

# AGENTS.md

## Build & Test
- Install deps: `npm ci`
- Run tests: `npm test -- --run`
- Lint: `npm run lint`

## Conventions
- TypeScript strict mode; no `any`
- Every API change requires an integration test

## Security Policy
- Never log credentials, tokens, or secrets
- Secrets must come from environment variables only
2

Step 2: Apply the quick symlink workaround for Claude Code

From your project root, create a symbolic link named CLAUDE.md pointing at AGENTS.md using `ln -s AGENTS.md CLAUDE.md`. Claude Code follows the symlink and reads the AGENTS.md content transparently, so there is no duplication to maintain. Commit the symlink to git so collaborators get it automatically. Caveat: symlink creation on Windows requires admin privileges (or Developer Mode), so macOS/Linux-heavy teams benefit most from this approach.

cd /path/to/project
ln -s AGENTS.md CLAUDE.md
git add CLAUDE.md
git commit -m "chore: link CLAUDE.md to canonical AGENTS.md"
3

Step 3: Use the zero-maintenance import workaround

If you want to avoid symlinks entirely, create a CLAUDE.md that contains exactly one line: `@AGENTS.md`. Claude Code processes the `@` import directive at runtime and pulls in the full AGENTS.md content, reading everything below it normally. This works cross-platform (no Windows symlink problem) and stays in sync automatically because there is only ever one copy of the content. Verify it works by asking Claude Code to summarize its loaded project instructions — import directives fail silently if the path is misspelled.

# Create the minimal import-only CLAUDE.md
echo '@AGENTS.md' > CLAUDE.md

# Resulting file contents:
# @AGENTS.md
4

Step 4: Automate CLAUDE.md generation with a pre-commit hook

For teams that need Claude-specific notes alongside shared instructions, write a small shell script that concatenates a comment header onto the AGENTS.md content and writes the result to CLAUDE.md. Wire it into a pre-commit hook (e.g., via pre-commit) triggered whenever AGENTS.md changes. This guarantees both files stay in sync without manual intervention, survives Windows (it commits a plain file, not a symlink), and lets you inject Claude Code–specific guidance that Cursor and Devin simply ignore. Never hand-edit the generated CLAUDE.md — edits are overwritten on the next sync.
