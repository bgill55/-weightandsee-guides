Technical contrast: statistical perturbation vs cryptographic post‑processing

SynthID altered token probability distributions to embed a detectable pattern, which reduced creative‑writing quality. Claude 4 instead performs a post‑generation hash and attaches a verification header, preserving generation quality while still providing provable provenance.

Creator workflow and policy impact

Open‑source models sidestep the watermark battle

Models like Llama 4 remain watermark‑free because their weights can be modified by anyone. This freedom allows developers to add or strip provenance signals at will, but also means no standardized verification exists for open‑source outputs.

⚙️ Technical Background

AI watermarking embeds a hidden signal in generated text to prove its origin. Early approaches such as Google’s SynthID modify token probabilities to create a statistical pattern detectable by downstream tools. More recent methods, like Anthropic’s cryptographic signatures, compute a hash of the output and attach a signed metadata header, which survives downstream transformations while adding minimal latency.
