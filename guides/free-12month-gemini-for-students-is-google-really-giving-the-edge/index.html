Step 2: Store the API key securely as an environment variable

Copy the API key shown after activation. In your local shell or Colab notebook, export it as `GEMINI_API_KEY`. This variable will be read by both curl and Python scripts, keeping the key out of source code.

import os

Step 3: Test the REST endpoint with curl

Use curl to send a simple prompt to the Gemini 3.5 model. The request includes the bearer token header and a JSON payload. The response will contain the generated text in the `candidates[0].output` field.

curl -X POST https://generativeai.googleapis.com/v1beta/models/gemini-3.5:generateContent \
  -H "Authorization: Bearer $GEMINI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Summarize the attached PDF"}'

Step 4: Run a Python script to generate content

Create a short Python program that reads the environment variable, builds the request, and prints the model’s output. This script demonstrates how to integrate Gemini into larger workflows (e.g., auto‑generating code snippets or study notes).

import os, requests, json

key = os.getenv("GEMINI_API_KEY")
url = "https://generativeai.googleapis.com/v1beta/models/gemini-3.5:generateContent"
payload = {"prompt": "Explain quantum entanglement in 150 words"}
headers = {
    "Authorization": f"Bearer {key}",
    "Content-Type": "application/json"
}
resp = requests.post(url, headers=headers, json=payload)
print(json.loads(resp.text)["candidates"][0]["output"])

Step 5: Mount the free Cloud Storage bucket in a Colab notebook

In Google Colab, use the `gcsfs` library (pre‑installed in the default environment) to mount the bucket created for you. This lets you read/write large datasets (e.g., a 30 GB research corpus) directly from the notebook without leaving the Google Cloud network.

from google.colab import drive

drive.mount('/content/drive')
# The bucket appears under /content/drive/MyDrive/gemini-student-
# Example: list files
!gsutil ls gs://gemini-student-/

💡 Pro Tips

Pro Tip: Refresh the OAuth token every 24 h (or set `expires_in` to a high value) to avoid authentication errors during long training runs.
Pro Tip: Enable the Gemini Plugins payload to attach a citation database or plagiarism checker—simply add a `plugins` array to your JSON request.
Pro Tip: Monitor token usage in the Google AI dashboard; set an alert at 80 % of your monthly quota to avoid unexpected throttling.
Pro Tip: When working with images, encode them as base64 and include them in the `content` field; the same REST endpoint handles multimodal prompts.

⚠️ Common Pitfalls

Watch Out: Pitfall 1: Forgetting to cancel before the 12‑month window ends—Google auto‑migrates you to a paid quota, which can lead to surprise charges.
Watch Out: Pitfall 2: Assuming the 200 GB storage is unlimited file count—there is a per‑object limit of 5 TB total; large numbers of tiny files can hit metadata limits.
Watch Out: Pitfall 3: Using the same API key across multiple projects without scoping; this can make it harder to audit usage per class or assignment.

❓ Frequently Asked Questions

Who is eligible for the free 12‑month Gemini plan?

Any currently enrolled college or university student with a verified .edu email address and a credit‑card for identity verification.

What are the token limits compared to other free tiers?

Gemini 3.5 offers 500 k input tokens per month (≈5× the free tier of GPT‑5.5 and 10× Claude 4’s free tier), plus 200 GB of Cloud Storage.

How do I mount the provided Cloud Storage bucket in Colab?

Use `drive.mount('/content/drive')` to attach your Drive, then access the bucket via `gsutil` commands (e.g., `!gsutil ls gs://gemini-student-/`).

Is my data used to train future Gemini models?

Google states that data processed under the student plan is not used for model training and is encrypted both at rest and in transit.

What happens after the 12‑month free period ends?

Your account is automatically switched to the paid quota ($0.02 per 1 k input tokens). You can cancel before the renewal date to avoid any charges.

Can I fine‑tune Gemini on my own coursework?

Yes. Gemini 3.5 runs on a 7‑billion‑parameter model that fits on a single TPU v4 slice, allowing on‑device fine‑tuning without extra cloud cost.
