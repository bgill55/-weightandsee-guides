How to Build an Offline Creative Workflow with Flux 2, ComfyUI, and Ollama

This guide demonstrates how to construct a fully local, cost-free AI art generation pipeline by integrating Flux 2 for image synthesis, ComfyUI for graph-based orchestration, and Ollama for local LLM text processing. You will learn how to install these tools, configure the workflow nodes, and execute high-fidelity generative tasks without any cloud API dependencies. This setup ensures maximum privacy and data ownership while achieving speeds comparable to paid cloud services.

📋 Prerequisites

  • A workstation with a powerful GPU (e.g., NVIDIA RTX 4090) with at least 12GB+ VRAM recommended for Flux 2.
  • Python 3.10 or newer installed on your operating system.
  • Basic familiarity with command-line interfaces (CLI) and file directory management.

📝 Step-by-Step Guide

1

Step 1: Install Ollama and Run a Local LLM

Download and install Ollama, which acts as the local Large Language Model engine to process and refine your text prompts. Once installed, open your terminal and pull a lightweight, efficient model like Llama 3 to handle text generation.

# Install Ollama (Linux/macOS)
curl -fsSL https://ollama.com/install.sh | sh

# Pull and run a 7B or 8B parameter model
ollama run llama3:8b
2

Step 2: Clone and Install ComfyUI

Clone the ComfyUI repository from GitHub to manage your graph-based execution flow. Navigate into the directory and install the necessary Python dependencies using pip to ensure the backend can communicate with your GPU.

# Clone the repository
git clone https://github.com/comfyanonymous/ComfyUI

# Navigate into the folder
cd ComfyUI

# Install Python dependencies
pip install -r requirements.txt
3

Step 3: Download and Integrate Flux 2 Checkpoints

Download the Flux 2 model checkpoint files (safetensors format). Move these files into the specific models directory within your ComfyUI folder so the inference engine can access them for image generation.

# Move downloaded Flux checkpoint to the ComfyUI models directory
# Example path structure:
# ComfyUI/models/checkpoints/flux2-dev.safetensors

# Or specifically for the unet depending on your custom node setup:
# ComfyUI/models/unet/flux2-dev.safetensors
4

Step 4: Wire the Workflow in ComfyUI

Launch ComfyUI and load the workflow graph. Add an 'Ollama' node or text input node connected to your local LLM, and connect its output to the 'Prompt' input of the Flux 2 KSampler or Image Generation node. This bridges your text processing with the image synthesis engine.

# No CLI command needed. 
# In the ComfyUI interface:
# 1. Add 'OllamaPrompt' node -> Set Model: 'llama3:8b'
# 2. Add 'FluxSampler' node -> Load Checkpoint: 'flux2-dev.safetensors'
# 3. Connect Ollama Output -> Flux Prompt Input
5

Step 5: Execute Local Generation

Ensure your network cable is unplugged or Wi-Fi disabled to verify offline status. Press the 'Queue Prompt' button in ComfyUI to execute the workflow. Your local GPU will handle the inference for both text refinement and image generation.

# Run ComfyUI
python main.py --listen 0.0.0.0

# Access the UI at http://127.0.0.1:8188 and click 'Queue Prompt'

💡 Pro Tips

Pro Tip: Use quantized models (e.g., `q4_0`) in Ollama to reduce VRAM usage, leaving more memory available for the Flux 2 image generation process.
Pro Tip: If you encounter Out of Memory (OOM) errors, reduce the image resolution or batch size in the ComfyUI 'Empty Latent Image' node.
Pro Tip: Update your NVIDIA GPU drivers to the latest Studio Driver release for optimal TensorRT performance with Flux models.

⚠️ Common Pitfalls

Watch Out: Incorrect Model Paths: Placing Flux checkpoint files in the wrong folder (e.g., root directory instead of `models/checkpoints`) will cause 'File not found' errors.
Watch Out: Port Conflicts: Ensure Ollama is running on its default port (11434) so ComfyUI custom nodes can successfully query the local API.
Watch Out: Python Version Mismatch: Running ComfyUI on Python versions older than 3.10 often leads to dependency installation failures.

❓ Frequently Asked Questions

Can I run this setup on a GPU with less than 12GB of VRAM?

It is possible but difficult. You will likely need to use significantly lower image resolutions and enable CPU offloading for the LLM or the UNet, which will drastically increase generation time.

Do I need an internet connection once the software is installed?

No. Once you have downloaded the models (Ollama model, Flux checkpoint) and installed the repositories, you can disconnect your machine entirely and run the pipeline offline.

Why use Ollama instead of typing the prompt directly into ComfyUI?

Ollama allows you to use an LLM to expand simple concepts into detailed, high-fidelity prompts automatically, acting as an AI creative director within your local pipeline.
