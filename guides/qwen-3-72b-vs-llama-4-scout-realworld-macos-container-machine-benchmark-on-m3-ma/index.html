📝 Step-by-Step Guide

1

Step 1: Install Ollama and Pull Models

Install Ollama on your M3 Max MacBook, then pull the Qwen 3 72B and Llama 4 Scout models using the commands:

ollama pull qwen3-72b
ollama pull llama4-scout
2

Step 2: Launch Models in macOS Container Machines

Launch each model inside a macOS Container Machine using the container flag:

ollama run qwen3-72b --container
ollama run llama4-scout --container
3

Step 3: Run Benchmarks and Measure Performance

Send a 128‑token prompt to each model, record round‑trip latency, tokens per second, and log power draw with a USB‑C wattmeter.

ollama eval qwen3-72b --prompt ""
ollama eval llama4-scout --prompt ""

❓ Frequently Asked Questions

What are the main differences between Qwen 3 72B and Llama 4 Scout?

Qwen 3 72B has 72 B parameters and consumes more power, while Llama 4 Scout is smaller, runs faster, and uses less energy.

Can I run these models on any Mac?

The benchmark was performed on an M3 Max MacBook; older or lower‑spec Macs may struggle with the 72 B model.

How do I accurately measure power draw?

Connect a USB‑C wattmeter between the MacBook charger and the power outlet, and log readings during inference.

Do I need to use the '--container' flag with Ollama?

Yes, the '--container' flag ensures the model runs inside a macOS Container Machine, isolating resources and providing consistent benchmarking conditions.

Is offline inference feasible for production workloads?

For privacy‑focused or edge use‑cases, the M3 Max can handle moderate workloads, but large‑scale research may still require server‑grade hardware.
