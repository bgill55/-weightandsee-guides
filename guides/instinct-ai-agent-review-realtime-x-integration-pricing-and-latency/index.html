📝 Step-by-Step Guide

1

Step 1: Launch the Instinct inference server

Run the Instinct server with a single command that exposes port 8080 and loads the default model. This starts the lightweight transformer stack ready to receive posting and streaming requests.

instinct‑serve –port 8080 –model instinct‑v1
2

Step 2: Send a test request to X

Use curl to post a sample message to the live X feed. The payload must include a "text" field; optionally include "media_url" for attachments.

curl -X POST http://localhost:8080 -H "Content-Type: application/json" -d '{"text":"Hello X from Instinct!"}'
3

Step 3: Benchmark against Claude 5 and Gemini 3.7

Run the provided benchmark script to measure latency, cost, and concurrency for each model. The script outputs average response times and per‑thousand‑post costs.

python benchmark.py --models instinct claude5 gemini37 --requests 1000
4

Step 4: Inspect runtime metrics with the debug endpoint

Query the built‑in /debug endpoint to retrieve compact JSON containing token usage, latency stats, and queue length for the current session.

curl http://localhost:8080/debug | jq '.'
5

Step 5: Review pricing and scaling configuration

Check the pricing table in the Instinct docs and adjust the queue manager settings (e.g., virtual‑core count) to match your expected traffic pattern.

instinct‑serve --help | grep -i "queue"

❓ Frequently Asked Questions

Do I need a separate API key for each model?

Yes. Instinct uses its own embedded token, while Claude 5 requires a CLAUDE_API_KEY and Gemini 3.7 needs a Google Cloud API key. These should be set as environment variables before issuing requests.

Can Instinct handle multimedia posts?

The minimal JSON schema only mandates a "text" field, but you may optionally include a "media_url" field to attach images or videos when posting to X.

Why does Gemini 3.7 sometimes exceed 200 ms latency?

Its additional safety filter checks output against a blacklist; when the filter queue is busy, it adds up to ~50 ms per request.

Is the debug endpoint safe for production use?

The /debug endpoint is intended for local development and testing. Exposing it publicly can leak internal metrics, so it should be disabled or restricted in production deployments.

How do I scale Instinct for thousands of concurrent posts?

Scale horizontally by running multiple server instances behind a load balancer and adjust the `--max-concurrency` flag to match your cluster size.
