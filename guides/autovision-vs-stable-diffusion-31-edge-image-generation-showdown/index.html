📝 Step-by-Step Guide

1

Step 1: Set Up API Credentials

Create accounts on AutoVision, Hugging Face, and PromptFlow. Store the API keys in environment variables for secure access. On a Unix shell, export them as:

```bash
export AUTOVISION_API_KEY=your_autovision_key
export HF_API_KEY=your_huggingface_key
export PROMPTFLOW_TOKEN=your_promptflow_token
```
2

Step 2: Test Image Generation APIs

Verify that each image model is reachable by sending a simple POST request. Use curl or a small Python script to generate a test image.

```bash
# AutoVision
curl -X POST https://api.autovision.com/v1/generate \
  -H "Authorization: Bearer $AUTOVISION_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A futuristic city skyline", "size": "1024x1024"}' > autovision.png

# Stable Diffusion 3.1 via Hugging Face
curl -X POST https://api-inference.huggingface.co/models/stabilityai/stable-diffusion-3.1 \
  -H "Authorization: Bearer $HF_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"inputs": "A fantasy landscape"}' > sd3.1.png
```
3

Step 3: Build a PromptFlow Workflow

Log into PromptFlow’s web UI, create a new workflow named "Edge Image Generator", and drag connectors for AutoVision and Stable Diffusion. Configure each step to accept a prompt, pass the result to the next step, and store the image URLs in a final output node. After building, click the "Run" button to execute the workflow and preview images side‑by‑side.

```json
{
  "name": "Edge Image Generator",
  "steps": [
    {
      "id": "auto",
      "type": "api",
      "connector": "AutoVision",
      "inputs": {"prompt": "{{prompt}}", "size": "1024x1024"}
    },
    {
      "id": "sd",
      "type": "api",
      "connector": "StableDiffusion3.1",
      "inputs": {"prompt": "{{prompt}}", "size": "1024x1024"}
    },
    {
      "id": "output",
      "type": "output",
      "inputs": {
        "autoImage": "{{auto.image_url}}",
        "sdImage": "{{sd.image_url}}"
      }
    }
  ]
}
```

❓ Frequently Asked Questions

Can I run Stable Diffusion 3.1 locally instead of using the Hugging Face API?

Yes, download the model weights from Hugging Face and run them on a GPU‑enabled machine using the official Stable Diffusion repo.

How do I compare image quality metrics between AutoVision and Stable Diffusion?

Use perceptual similarity metrics like LPIPS or SSIM on a set of test prompts, and store the scores in PromptFlow’s output node for analysis.

What if my prompt includes copyrighted text or imagery?

Both AutoVision and Stable Diffusion enforce content policies; ensure your prompts comply with their terms of service to avoid rejection.

Can I integrate other models, such as DALL‑E 3, into the same PromptFlow workflow?

Yes, add a new API connector for DALL‑E 3 and configure the workflow to route prompts to it based on user selection.
